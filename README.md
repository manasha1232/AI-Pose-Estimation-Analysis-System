# AI-Powered Human Pose Estimation & Motion Analysis System

An end-to-end Computer Vision project for real-time human pose estimation, kinematic body landmark detection, ergonomic posture evaluation, and autonomous pose classification.

## System Architecture
```
Input Feed -> MediaPipe Pose Pipeline -> 33 Landmarks -> Angle Engine -> Classification & Overlay
```
